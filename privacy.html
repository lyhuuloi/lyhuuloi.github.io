Privacy Policy

Last updated: 3 November 2026

This policy covers ben-mmo-studio, a private tool that Ben Studio uses to manage its own YouTube channel.

What the tool accesses

When the channel owner signs in with Google, the tool requests access to that owner's YouTube account through the YouTube Data API and the YouTube Analytics API. It uses that access only to upload the studio's own videos, captions and thumbnails, manage the channel's playlists and metadata, and read the channel's own performance reports.

What the tool does not do

  • It does not access any other person's Google or YouTube account.
  • It does not collect, sell or share personal data, and it shows no ads.
  • It does not transfer Google user data to third parties.

Storage

The OAuth tokens are stored only on the studio's own computer, readable only by its owner. Analytics reports are kept privately to improve the channel's videos.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be raised through this site's issue tracker.
